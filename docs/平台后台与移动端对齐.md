# 平台后台与移动端对齐

更新：2026-09-12。本轮范围为本地开发与联调。

## 使用边界

Web 仅供平台管理员使用。俱乐部、队长、主办方继续使用 iOS；原有移动端组织权限保留。平台会话与移动端会话分别存储、分别鉴权，不能混用。用户发布的赛事与社区内容继续直接发布，平台负责后续巡查与下架。

| 模块 | 平台操作 | 移动端结果 |
| --- | --- | --- |
| 工作台 | 真实数量、待审核报名、未解决反馈、最近发布、业务跳转 | 与移动端使用同一数据库 |
| 内容运营 | 轮播、广告、指南、外部视频；图片上传与署名；城市、时间、排序；草稿预览、发布、下架 | 仅加载已发布且城市、时间匹配的内容；视频收藏按内容 ID 保存 |
| 赛事 | 新建、修改、下架、恢复，关联报名与赛程 | 公开列表同步；下架阻止新报名，已有参与者保留历史入口 |
| 报名与纠错 | 查询、审核、修改名单及状态 | 状态与名单同步；保留修改前后快照；撤销资格前需处理关联赛程 |
| 赛程与比分 | 代排赛、修改、取消、终场比分纠错 | 共用队伍资格、时间及场地冲突校验 |
| 机构与队伍 | 机构新建修改、关联账号/赛事/队伍；队伍资料与名单；移除社区成员 | 当前资料同步；历史报名名单不随队伍修改；负责人不可移除 |
| 社区巡查 | 查询发布及申请、下架恢复、有理由调阅申请会话 | 下架阻止新增参与；历史保留；调阅不改变用户未读状态 |
| 用户与反馈 | 账号资料、停用恢复、反馈处理与回复 | 停用撤销旧会话；恢复后需重新登录；用户能查看反馈回复 |
| 操作日志 | 查询原因、操作对象、时间、修改前后 | 业务修改与日志写入同一事务 |

## 运行

在已有本地数据库上先构建、迁移，再启动服务。迁移通过 `CREATE/ALTER ... IF NOT EXISTS` 增量执行，内容种子只插入不存在的记录，不覆盖运营编辑。

```sh
npm run db:start
npm run build
node - <<'JS'
const {Pool}=require('pg');
const {migrate,databaseURL}=require('./apps/api/dist/database');
(async()=>{const db=new Pool({connectionString:databaseURL()});try{await migrate(db);}finally{await db.end();}})().catch(e=>{console.error(e);process.exitCode=1});
JS
npm run dev
```

后台地址：`http://127.0.0.1:5173`；API：`http://127.0.0.1:3001/api/v1`。

首次创建平台管理员：设置 `PLATFORM_USERNAME`、`PLATFORM_PASSWORD` 环境变量后运行 `node apps/api/dist/platform-setup.js`。用户名 3–40 位英文、数字、下划线或连字符；密码至少 12 位。该命令拒绝 production 环境，不提供默认密码，也不覆盖已存在账号。本机已创建的联调凭据位于 `.local/platform-credentials.json`，权限 0600，未纳入 Git。

上传文件默认保存在 `.local/platform-uploads`，可用 `UPLOAD_DIR` 指定目录。仅支持 10MB 以内 JPEG/PNG，校验文件签名；返回随机素材 ID，不使用用户文件名拼接路径。数据库与上传目录需一同保留；此版本没有接入云对象存储。已有 CC0 项目图片从 iOS Media 目录读取。

## 接口契约

以下接口均以 `/api/v1` 为前缀。平台接口使用独立 Bearer token。

| 方法与路径 | 输入与行为 |
| --- | --- |
| POST `/platform/sessions` | `{username,password}`；成功返回 `{token,account}`；会话 8 小时；连续失败限制登录 |
| GET `/platform/me` / DELETE `/platform/session` | 当前平台账号 / 退出 |
| GET `/platform/overview` / `/platform/lookups` | 工作台统计 / 表单选择数据 |
| GET `/platform/:resource` | `q,status,parent,offset,limit`；每页最多100；返回 `{rows,total}` |
| POST `/platform/:resource` | `{reason,values}`；仅机构、赛事、赛程支持新增 |
| PATCH `/platform/:resource/:id` | `{version,reason,values}`；版本过期返回409；按资源校验字段 |
| GET `/platform/teams/:id/members` | 队伍负责人及社区成员 |
| POST `/platform/teams/:id/remove-member` | `{accountId,reason}`；保留历史报名 |
| POST `/platform/applications/:id/inspect` | `{reason}`；记录调阅日志后返回申请说明与消息 |
| GET / POST `/platform/assets` | 素材列表 / `{data:base64,attribution,reason}` |
| POST `/platform/content` | `{kind,reason,data}`；仅保存草稿 |
| PUT `/platform/content/:id` | `{version,reason,operation,data?}`；operation为save/publish/unpublish |
| GET `/content?city=上海` | 无需登录；全国内容加指定城市内容；按投放时间过滤 |
| GET `/content/assets/:id` | 素材文件，正确MIME及nosniff |

列表资源包括 organizations、teams、tournaments、registrations、matches、posts、applications、users、feedback、audit、content。平台记录字段遵循数据库 snake_case；移动端既有 camelCase 契约保留。赛程写入表单使用 `homeRegistrationId/awayRegistrationId/startsAt/endsAt/homeScore/awayScore` 等 camelCase 字段。

`parent` 在报名、赛程列表中为赛事ID；申请列表为发布ID；审计为资源ID；队伍、账号、赛事列表为机构ID。搜索、分页由服务端完成。申请列表与搜索均不包含私有申请说明。

内容data字段：title、subtitle、body、city、startsAt、endsAt、assetId、attribution、sort、action、sourceURL。action为`{type,id,url}`；type支持none/video/guide/tournament/community/external。外部地址必须HTTPS；指南/赛事目标发布前检查有效性。时间为ISO8601，空值表示不限。编辑草稿不改变published；发布复制完整草稿；下架清空published；每次操作递增version并审计。

iOS启动、切换城市、回到前台及前台轮询时刷新内容，首页下拉也刷新。请求失败保留上次成功缓存并显示同步失败提示；成功返回空数组会清空旧内容。缓存仍按当前城市和有效期过滤。已加载内容的下架以成功刷新为生效点，离线状态不承诺即时撤回。

## 当前交付边界

这是平台管理与既有移动端业务的本地对齐，不包含生产部署、短信/真实身份、正式无人机足球资格规程、支付、直播推流、运营账号分级权限。平台管理员目前拥有全部平台模块权限；所有普通业务角色继续受原有移动端权限控制。没有新增平台替用户发消息或直接操作用户会话的功能。
