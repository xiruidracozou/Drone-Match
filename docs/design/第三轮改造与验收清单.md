# 第三轮 iOS 产品改造

用户要求：参照足球中国功能、蓝色视觉、真实用户可用、主动使用设计技能及真实 App 案例。此次完成标准不能缩减为换色或删栏目。

## 设计依据

已阅读 taste-skill 的 brief inference / overhaul / preservation，以及 Anthropic frontend-design。原生 SwiftUI 保留系统交互；Web 专用框架规则不机械套用。

实际查看官方 App Store 截图（仅作为研究，不打包到 App）：
- FotMob：https://apps.apple.com/us/app/fotmob-soccer-live-scores/id488575683 。日期选择、赛事分组、紧凑对阵信息。
- Strava：https://apps.apple.com/us/app/strava-run-bike-hike/id426826309 。内容、社群与个人运动记录分别组织。
- DJI Fly：https://apps.apple.com/us/app/dji-fly/id1479649251 。影像展示与清晰操作层分离。
- 活动交互依据：https://support.strava.com/en-us/articles/15401534-browse-events-on-mobile 。城市、日期和活动形式筛选。
- 功能依据：用户提供的足球中国十张截图，不把截图推断为其后台真实实现。

视觉方向：钴蓝 #245CF5、海军蓝 #102A56、冰蓝 #EAF1FF、页面 #F4F6FA、主体 #172239、辅助 #63728A。标题用系统中文粗体，正文系统常规字体，数字使用等宽数字。20pt 页面边距，8pt 间距基准；主内容 18pt 圆角、输入 12pt、状态 6pt，避免所有元素同形同权重。动效只反馈点击、筛选与状态变化。

首页结构：蓝色品牌与城市 → 直接搜索 → 六项服务入口 → 当期赛事重点 → 招募与约赛 → 入门内容。赛事、队伍服务、生涯、视频、我的都有对应数据路径；不以虚构成绩、计数或图片充实页面。

## 当前进展（第一批，不代表整项完成）

已编码：蓝色主题及首页；战队招募、飞手找队、训练约赛、志愿活动的发布/查询/申请/处理；申请中心；双方私有留言；公开队伍与机构目录；CC0 真实设备照片的入门文章。保留原赛事报名与队伍编辑流程。

验证：14 项 HTTP + 独立 PostgreSQL 测试通过；iOS 原生构建通过。新测试有红→绿证据，覆盖招募入队、发布权限、申请幂等、约赛并发、取消、撤回、私有留言及目录隐私。模拟器设备已启动、安装及启动成功，但 CUA 获取 Simulator 窗口连续 `timeoutReached`；运行进程采样显示主线程在事件循环等待。不能据此断言 App 卡死或 Mac 锁屏。已询问桌面可操作状态，视觉和操作验收未完成。

第一批当前导航为首页/赛事/队伍/我的，属于开发中的过渡状态；五栏目标、生涯、视频、赛事赛程成绩、成员完整生命周期、客服账号能力继续保留，不能以当前四栏宣布全部完成。

社区剩余事项：列表当前最多返回最近 100 条，需要分页；约赛尚无持续时长和跨活动冲突检查；志愿者签到未实现；队伍成员加入后退出/移除与历史待补。上述未完成项不得由当前测试覆盖范围外推为完成。

视频素材研究：FAI 官方提供 2025 无人机足球世锦赛回放入口：https://www-2025.fai.org/wdsc2025-livestream 。后续可提供官方来源观看入口，不能把它当作本平台持有的直播源或虚构现场直播。
