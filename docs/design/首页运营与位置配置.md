# 首页运营与位置配置

当前实现（2026-09-12）：轮播、广告、指南与视频已改由平台后台发布，iOS读取已发布内容。没有投放统计或广告交易功能。完整流程见[平台后台与移动端对齐](../平台后台与移动端对齐.md)。

## 首页内容顺序

城市／搜索／消息 → 实拍轮播 → 六个常用入口 → 实际待办（有才显示）→ 当地可报名赛事 → 商业推广（有才显示）→ 招募与约赛 → 项目入门。

普通字号保留紧凑三列入口；辅助字号使用单列入口与独立搜索行。轮播是图片与内容入口，不是自动播放视频。当前两页分别进入视频栏目和器材指南。自动切换间隔6秒，支持暂停；系统减少动态效果或 VoiceOver 时不自动切换。

## 预留推广位

平台「内容运营」中新建广告，选择图片、城市、投放起止时间、排序及HTTPS落地页，保存草稿并核对预览后发布。旧版空的 HomePromotions.json 和对应本地广告模型已移除。

首页显示当前城市有效广告中排序最前的一条，带“广告”标签；全国只显示全国投放。无匹配广告时不占位。时间起点包含、终点排除。服务端过滤发布状态、城市与时间，客户端对缓存再次校验，成功刷新后下架生效；离线时提示同步失败并保留有效缓存。

轮播每6秒自动切换，保留暂停、VoiceOver及减少动态效果适配。指南入口标题、图片与正文也读取发布内容。视频按稳定内容ID收藏，兼容原单视频收藏迁移。

## 位置模型

`selectedCity` 是用户选择的浏览城市，由首页、赛事、招募和公开目录共用并保存在本机。定位结果是独立的候选位置，不自动覆盖该值。最近选择保留6个非“全国”城市，去重并按最近使用排序。

城市目录取自 modood/Administrative-divisions-of-China 静态数据（WTFPL v2），本次含31个大陆省级行政区、369条城市层级记录。直辖市归为城市，部分省直辖县级市单列；区县仅作中文检索别名。港澳台未包含在该来源快照中。更新目录需核对名称与现有赛事、机构的 city 值；来源许可见 Media/Cities-LICENSE.txt。

“有赛事或俱乐部的城市”由已有内容产生，仅是快捷入口；无内容城市仍可通过完整目录选择，并展示真实空状态。城市拼音检索支持全拼或连续片段，不提供首字母缩写检索。

Core Location 使用城市级定位精度，逆地理编码由系统完成。本项目后端只接收浏览城市过滤条件，不接收坐标。用户拒绝定位后仍能选城；不在目录中的定位结果提示手动选择。当前没有 POI 搜索、地图落点、区县筛选或距离排序。
