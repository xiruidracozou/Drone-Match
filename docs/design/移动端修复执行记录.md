# iOS 全端修复执行记录

依据用户指定的 [mobile-app-ui-design](https://github.com/ceorkm/mobile-app-ui-design/blob/main/SKILL.md) 及其 industry-conventions 引用。已读取原文；保留原生 SwiftUI、SF Symbols 和动态字体，不套用其 Web 框架示例。用户已经授权直接修改，不增加设计确认关卡。

方向：真实体育工具与社群，白/深色中性底、钴蓝关键操作、清晰赛事及队伍身份。首页优先近期可报名赛事和与用户有关的事项；取消通用宣传口号。五栏：首页、赛事、生涯、视频、我的。生涯明确区分报名、队伍关系、实际出场；不得虚构成绩或成长等级。视频清楚标记官方外部观看与平台直播的区别。

顺序：
1. 修复搜索/个人发布的100条截断、入队之后的入口、撤回重提、消息已读；HTTP + 独立数据库验证。
2. 统一全端布局、文字、按钮、筛选、加载/空/错误/完成状态；补充资料编辑和反馈。
3. 原生构建、模拟器逐页检查、核心操作及深色验证。

现有开发账号与数据不能冒充正式账号与赛事。没有短信服务、正式身份服务和自有直播源时，保留准确的能力边界。

- 五栏导航：首页、赛事、生涯、视频、我的；保留原赛事报名和队伍名单维护。
- 首页取消通用宣传口号，以近期可报名赛事和个人申请入口组织；同步城市选择。
- 赛事详情分为概览、规程、参赛队伍、赛程。参赛队伍读取审核通过的实际报名，不展示私有名单。
- 主办方手动发布/修改/取消对阵、录入比赛总比分；同赛事内队伍/场地冲突与并发版本保护。
- 生涯展示当前队伍赛程、比赛结果、报名和社区参与记录，并明确这些不是个人出场战绩。
- 视频提供经 FAI 官方赛事页验证的 2025 世锦赛回放合集；原生浏览器打开外部来源、本机收藏和搜索。没有伪造直播、预告、播放次数或比赛画面。
- 我管理的和我加入的队伍统一入口；成员查看、负责人移除、本人退出。
- 找队邀请必须选择本人的同级别队伍，接受后建立入队关系；旧版未关联队伍的联系记录仍能保留。
- 申请撤回后可重提，已接受记录不会被重复点击重置；会话保留。
- 服务端条件查询/分页，修复原100条截断；社区列表按条件首批加载并支持“加载更多”，首页首屏只取3条社区动态。搜索防抖与取消保护，个人发布和队伍动态按归属查询。目录和全局搜索仍会分批读取全部匹配记录，超大数据量需进一步按需加载。
- 未读留言隔离、进入会话标记已读、前台自动刷新；不是系统推送。
- 显示名称修改、反馈保存及私人提交记录、浅色/深色/跟随系统设置。
- 固定深色聊天气泡背景色，白字对比度约5.37:1；主页面用统一字体层级和4/8pt间距。
- 截止时间在客户端重新判断，防止缓存报名状态在过期后仍可点击。

## 2026-09-08 模拟器实机画面复核

环境：iPhone 17 Pro / iOS 26.4。用户解锁后，通过 CUA 实际读取 Simulator 页面和执行点击，不再以进程启动代替界面证据。

### 本轮发现并修复

1. 首页工具栏的 Label 被系统收缩为定位图标，城市名不可见。改为显式图标与文字；已看到“全国”“杭州”，选择杭州后只显示杭州赛事。
2. 首页及全局搜索的赛事行只有日期，没有月份，跨月结果容易误读。仅为此处赛事行增加月份；赛事页按月份分组的布局保持原样。已在“赛”的搜索结果中看到10月11/18/24日。
3. 深色下部分突出按钮继承浅蓝 accent，出现浅蓝底白字。统一为固定钴蓝底；已复核招募页按钮，其他同类操作使用同一颜色。
4. 空招募表单可以点击发布，缺项提示要提交后才出现。改为复用一处客户端校验来禁用按钮和显示具体缺项提示；补齐长度及时间检查，服务端校验仍保留。实际看到空表单禁用、选队缺失提示、缺少详细说明提示。

### 已执行的界面检查

- 五栏实际页面：主页、赛事、生涯、视频、我的。

## 2026-09-09 至 09-10 双账号与小屏验收收尾

环境：本地 API、iOS 26.4，iPhone 17 Pro 与新建的 iPhone SE（第3代）模拟器。继续使用 mobile-app-ui-design 的原生交互和状态验证方法。以下为 CUA 实际操作结果，覆盖指定路径，不代表正式上线能力或全部页面组合已验收。

### 社区完整操作

- SE 上以林教练发布“本地验收招募0909”，关联青空一队；实际输入并提交了标题、城市、队伍和说明。
- Pro 上以陈教练申请入队，留言提交成功，申请显示待处理。申请人随后发送一条会话留言，气泡出现且输入框清空。
- 林教练接受申请后，状态变为已接受；发布人阅读申请人的留言并回复，陈教练在另一模拟器看到同一回复。
- 申请人个人中心和申请中心均出现“1 条未读留言”；阅读后返回，两个入口的未读标识清除。
- “我加入的”出现青空一队，成员页显示负责人林教练与成员陈教练。点击退出并确认后，返回列表，“我加入的”为空，原有管理队伍远山飞行队及其3人名单显示仍在。没有把社区成员操作当成报名名单变更。
- 发布人通过界面关闭测试招募，状态显示已关闭；申请及留言历史保留。

### 视频真实播放

通过 App 的“观看官方回放合集”打开原生浏览器，加载 FAI 官方页面所指向的 YouTube 合集，点击播放，看到实际无人机足球画面及 00:20 / 1:59 的播放进度。已回到 App。此证据仅表示该环境下外部来源可播放，不代表自有直播或所有地区网络可用。

### 发现并修复的问题

1. 申请表单原先空内容仍可点击发送，且没有与服务端一致的500字符上限。新增 ApplicationDraft 统一校验，提示、按钮禁用和提交前检查共用；按去除首尾空白后的 UTF-16 长度与服务端对齐。保留找队邀请和约赛必须选队的要求。
2. 最大辅助字号下首页三列入口把四字标题挤成碎行。辅助字号切为单列图标加文字，普通字号仍为六入口三列。
3. 最大辅助字号下首页栏目标题、赛事页城市与筛选挤成竖排。标题操作和城市区域在辅助字号下纵向排列；赛事分类横向滚动并保持文字完整。
4. 固定宽度日期栏容不下放大的日期。辅助字号下赛事卡片和赛事行改为纵向信息结构，日期横排显示；普通字号保留侧边日期栏。
5. 视频分类在大字号下挤成圆形多行按钮。共用筛选文字保持完整，视频分类加入横向滚动。
